# tkinter → Qt 移植对等性清单(集成阶段逐项核对)

> 来源:游戏助手.pyw 功能清单(2026-09-12 契约侦察)。✅=已验证对等 / ⚠=有意差异(注明理由) / ❌=未移植

## 窗口与外壳
- [ ] 窗口标题/图标/任务栏 AppUserModelID
- [ ] geometry + 最大化状态持久化(500ms 防抖,clamp_window_bounds 校正)
- [ ] 最小尺寸 940×660;居中首次启动
- [ ] 侧栏:logo+「一键长草」+ SERIAL RUNNER、导航(主页/部署向导)、底部(使用帮助/设置)、管理员状态
- [ ] 全局运行条:状态圆点色、运行标题文案、进度、开始/停止、用时
- [ ] 关闭确认(运行中)+ 设置 flush
- [ ] 主题 4 套切换即时生效;字号档 4 档;字体族切换

## 主页
- [ ] 队列头(添加/刷新)+ 空列表占位文案
- [ ] 状态汇总条(自检 chips)
- [ ] 卡片:序号/名称/路径 elide+tooltip/状态行(TTL 探测)/启用开关/并行标记/↑↓/编辑/删除
- [ ] 拖拽排序 + order 持久化(_save_orders/_renumber_cards 语义)
- [ ] 日志面板:600 行上限、级别着色、跟随/暂停、复制/清空/导出/目录/导入/专注
- [ ] 计数标签「N 行 · 已丢弃较早 M 行」(200ms 节流)
- [ ] 分割比 home_log_ratio 持久化
- [ ] 运行中卡片控制禁用(_refresh_card_controls)

## 运行链路
- [ ] 开始:enabled 插件 → preflight(error 阻断/warn 确认)→ Runner 线程
- [ ] stop_event 停止 → 「停止中」→ stopped
- [ ] run_event 全 kind 更新运行条与状态(task_started/stage_changed/task_finished/queue_finished,并行变体)
- [ ] 日志 33ms 批量刷屏 + __DONE__ 收尾
- [ ] md 自动保存(5 万行缓冲、partial 标注、record_no)

## 页面
- [ ] 添加页:游戏/脚本下拉、扫描(线程+超时)、候选、自定义模式、保存
- [ ] 编辑页:全字段、高级选项折叠、浏览按钮、粘贴填充、保存/取消
- [ ] 部署向导:管理员说明、每游戏卡片(下载/一键配置/导入/扫描/恢复/检查)、完成标记 first_run_done
- [ ] 设置页:主题卡、字体族+字号、助手根目录+清缓存、日志保留
- [ ] 帮助页:HELP_TEXT 全文
- [ ] 粘贴填充对话框(add/edit 两模式,解析错误提示)
- [ ] 导入日志查看器(编码回退、20000 行截断、复制全部)

## 非目标(有意不移植)
- 深色标题栏 DWM hack(Qt 版可选,不作为验收项)
- tkinter 专属的 DPI/字体缩放 hack(_px/tk scaling)
